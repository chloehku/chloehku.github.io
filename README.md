# Chloe Chan — personal site

Files:

- `index.html` — the site
- `images/chloe-hero.jpg` — hero portrait (replace with a real photo if you want)

Optional upgrades (kept in `../chloe_site/` not in the deploy bundle):

- `chloe-portrait.jpg`, `chloe-avatar.jpg` — smaller variants if you swap them in
- hidden-HK photo plates are CSS placeholders; swap `.ph-1` … `.ph-6` classes for real `<img src="images/…">` tags when ready
